吉米奈的工作台 · 2.35.0
适用机型：使用 Apple M 系列芯片并运行 macOS 13 或更新系统的 Mac。可在苹果菜单的「关于本机」查看芯片名称。

安装
1. 双击「吉米奈的工作台-2.35.0-Apple-Silicon.dmg」。
2. 双击镜像里的「安装吉米奈的工作台」。若已有工作台正在运行，先用 ⌘Q 退出。
3. 安装器会把应用放入个人「应用程序」文件夹、固定到 Dock 并打开。以后点 Dock 上的「吉米奈的工作台」即可。首次进入时按提示使用自己的 Antigravity 账号登录。

你的 Mac 已装官方 Antigravity 2.35.0 时，安装器会读取本机副本；其他情况会从 Google 下载约 242 MB。请保持联网直至出现工作台窗口。安装所需 Python 和依赖已随包提供，安装过程使用当前用户权限。

开始使用
• 从左侧选择项目或新建会话，在中间输入需求。在右侧工坊点角色看任务状态，「本轮产物」可打开相关文件。
• 要派单给 Codex、Qoder CN 或 Gemini，先在本机安装并登录准备使用的执行端，再在聊天里说「把这个任务派给 Codex」。普通聊天可直接使用。
• 输入框上方的 MP 表示会话剩余上下文，HP 表示账户额度。不同模型能提供的数据不同，展开可查看来源和估算说明。
• 在「实时翻译卷轴 → 设置」选择服务，填自己的 API Key，保存并测试连接，再勾选「自动翻译」。纯中文模式在已匹配的可见思考摘要位置显示译文；「双语对照」可查看原文。自动翻译会把选中文本发给所选服务。也可选本机已启动的 Ollama。
• 在会话或文件上右击打开操作菜单。「场景设置」调整工坊风格，卷轴标题栏可收起。菜单栏「农庄外观」切换暖日、星夜或跟随系统。

更新与常见问题
• 升级时退出工作台，再打开新镜像里的安装器。个人会话和设置存放在应用外。Google 原版仍从原来的入口打开。
• 如果提示安装失败，可根据窗口最后一条错误重试。下载失败时先检查能否连接 Google。Dock 入口受管理时，可从访达「前往 → 个人」里的 Applications 文件夹打开已安装应用。
• 当前交付版使用 Apple Development 开发签名。另一台 Mac 若提示无法验证开发者并阻止打开，请联系提供方获取 Developer ID 签名并经 Apple 公证的发行版。
• 项目维护人员请从镜像中的「源码/README.md」和「源码/docs/HANDOFF.md」开始。
