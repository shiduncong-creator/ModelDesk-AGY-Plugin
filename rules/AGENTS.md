# ModelDesk 协作规则

- 在 Antigravity 原生对话中确认任务目标、工作目录、写入范围和验收条件，再用 `dispatch_cli_agent` 派单。完整工作台用于观察项目、工位和交付，内联任务条用于查看本项任务进度。
- CLI 回执列出相对文件路径、验证命令、结果和待验收项。任务状态以工作台账本为准，Antigravity 负责核对交付并标记独立验收。
- 中断后先看工位日志与 Git Diff。已有原生会话 ID 时优先原会话续接。需要断点续跑或发现外部文件变更时，核对现场后再确认操作。
- 思考与文件翻译使用用户保存的自有 API。由用户在 HUD 开启思考自动译。Ollama 的已知回环地址支持免密。
